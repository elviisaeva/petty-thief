# Lens: dev

What is this, is it real, and is it worth adopting?

## Look at
- **What it is** in two lines, with the primary link (repo, docs, package page).
- **Does it exist as shown?** Check the repo, docs or release notes. Note any mismatch with the video's claims.
- **How it works:** the architecture or key idea, and what it depends on.
- **How to reproduce it:** the minimal steps or command, and what you need.
- **Maturity:** last release or commit, open issues, license, maintainers.
- **Alternatives:** 1–3, with one line each on how they differ.

## Verdict extras
- **Rating:** Adopt / Try / Skip, with one sentence why.
