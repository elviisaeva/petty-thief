# Lens: design

What can I reuse from this look? Gather with `reference/design-extract.md`. Tag every fact with its source.

## Look at
- **Palette:** up to 8 hex values with their role (background, text, accent…).
- **Type:** font families, weights and sizes, only from CSS or font links. Never name a font from an image; describe it instead ("geometric sans, estimated").
- **Layout:** container width, columns, breakpoints.
- **Spacing and shape:** gaps, paddings, radii, borders, shadows.
- **UI patterns:** named (bento grid, sticky CTA, split hero…).
- **Mood:** 5 adjectives.
- **Logo** (identity work): how the mark is built (the idea, shapes, grid, wordmark vs symbol), its versions and how it behaves on carriers.
- **Notable screen decisions:** the 2–4 most interesting layouts or compositions in the case or product, and why they work (hierarchy, scale, crop, contrast).
- **Motion:** animations the case shows (logo animation, transitions, micro-interactions, GIF or video blocks): what moves, how (easing, rhythm, direction) and what it says about the brand. "None seen" when there is none.
- **Case structure** (Behance, Dribbble, portfolios): the screens in order, as a short numbered list, and what each one does (manifesto, hero, carriers, type sheet…).

## Verdict extras
- **Steal this:** the one move worth reusing, and how to apply it to the user's own work without copying the design.
