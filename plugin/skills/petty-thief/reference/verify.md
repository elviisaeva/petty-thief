# Verifying claims

- Every factual claim (a tool exists, a feature shipped, a number, "just launched", "free") is checked at the primary source: the official site, docs, repo, release notes, or the company's own post.
- Second-hand articles are not proof.
- When a claim checks out, link the source next to it.
- When it cannot be checked, list it under "Not verified" with what you tried. Never guess, round, or fill gaps.
- Metrics that are not visible are written as "not visible".
